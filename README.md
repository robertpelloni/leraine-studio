# leraine-studio (fork)

Fork/mirror of **Leraine Studio** — a cross-platform, portable, open-source VSRG (vertical scrolling rhythm game) chart editor written in C++ with SFML — kept in Robert Pelloni's rhythm-game reference library for his dance-game/charting work (StepMania, ITGmania, FCDM).

This copy has no root README of its own; for documentation, build instructions, and the canonical project, see the upstream Leraine Studio project.
