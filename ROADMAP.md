# Long-Term Project Roadmap

## Milestone 1: ArrowVortex & DDreamStudio Parity (Completed)
- [x] StepMania `.sm` file import and export.
- [x] Note transformations: Mirror, Expand (2.0x), Compress (0.5x), Reverse, Shuffle, Quantize.
- [x] Special note types: Holds, Rolls, Lifts, Mines, Fakes.
- [x] Timing tools: Stops, Scroll Velocities (SVs), Time Signatures, Tap BPM, Auto BPM, Snap to Peak.
- [x] Procedural Stream Generator (7 pattern types).
- [x] NPS / Difficulty Analyzer.
- [x] Audio hitsounds (Assist Tick) and metronome.
- [x] Unified Editor Dashboard with consolidated controls and guidance tooltips.

## Milestone 2: Advanced Visualization & Analysis (Next)
- [ ] Interactive FFT Spectrogram timeline rendering in `WaveFormModule`.
- [ ] Visual warped time representation for complex Scroll Velocity (SV) segments.
- [ ] Multi-chart tab switching within single project window.

## Milestone 3: Format Expansion & Portability
- [ ] Quaver (`.qua`) format reader/writer.
- [ ] BMS (`.bms`, `.bme`, `.bml`) format reader/writer.
- [ ] WebAssembly / Emscripten build pipeline for web-based browser editing.
